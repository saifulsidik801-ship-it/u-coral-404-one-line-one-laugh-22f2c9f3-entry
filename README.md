Entry for the make.fun competition **One Line, One Laugh**
([u-coral-404-one-line-one-laugh-22f2c9f3](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3)).

The program writes one funny line of at most 200 characters to
`/output/entry.txt`. Nothing else is submitted: the line is the whole entry.

## The line

> I asked the universe for a sign and it sent me a CAPTCHA — apparently even fate thinks I am a robot.

## Run

```sh
python3 main.py
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
